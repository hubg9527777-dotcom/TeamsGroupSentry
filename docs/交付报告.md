# TeamsGroupSentry 1.0.1 · 当前请求校验与可读性修复

## 三项修改

1. **消除历史缓存误报。** 当前 Teams 可见请求徽标、列表或官方请求面板才成立当前警示；无这些证据就撤下提示。缓存只按同一可见请求会话补正文，不能独立报警。旧 CACHE 会话警示立即隐藏，不删除群成员/身份审核历史，不推断接受或阻止结果。
2. **小栏末条，弹窗更多。** 保留已经取得的多条预览，不再被缓存末条覆盖。弹窗每个当前请求最多 10 条文字、每条 300 字、逐作者展示；小栏/展开栏只显示已取得的末条摘要。只有缓存一条时只显示一条，不能补造完整聊天历史；不扩展为普通群消息抓取。
3. **安全提醒与导航更醒目。** 中性深色背景、白色正文、红色请求边框/标题；安全提醒置顶，独立浅黄底深色粗体，优先显示“核实身份后再决定是否接受；切勿共享账号信息或授权登录”。无正文继续引导先预览，不能为看正文直接接受。底部三个导航按钮为浅底深字，固定可见，长消息只滚动内容区。

## 设计依据与验证

参考 [Kinneir / Margaret Calvert 的信息标识系统](https://designmuseum.org/designers/jock-kinneir-and-margaret-calvert) 中一致的字重、间距和功能颜色，以及 [Dieter Rams 的设计原则](https://www.vitsoe.com/us/about/good-design) 对易理解和减少无关装饰的要求。这里采用其信息层级思路，并非复制作品或声称获得认可。

实际界面自动验证：安全提示至少 7:1、导航文字/背景至少 4.5:1；置顶警告、固定底栏、多条/末条差别、编号、长文字不溢出。也已目视检查虚构预览。

**215 项回归通过**：Node 124、数据库/DOM 32、显示 28、单群绑定 8、姓名/本人查找 11、原生缓存 12。40 个脚本语法检查通过。全部虚构测试；正式 Chrome 安装后的现场效果、实际发送到提醒的延迟仍待验收。

## 安全和覆盖

公开版本 **1.0.1**，权限不变。原始源码、个人数据库和已安装目录未改；发布 ZIP 不含真实消息、缓存、截图、浏览器配置或审核数据。不自动预览、接受、阻止、回复、滚动或开链接，不读凭据或调用内部接口。

请求入口/列表/面板未渲染或不可见、页面冻结/关闭、Teams 改版时可能不提醒；不能以缓存替代当前界面证据。250ms 合并/5 秒补偿/1.8 秒读取超时不是对方发送起算的保证。预览副作用、全新请求预览前缓存、直接入群邀请者仍未验证。

更新前导出备份，保留原扩展 ID/加载路径，将安装 ZIP 文件更新到原目录，再重新加载扩展并刷新 Teams。不要卸载旧扩展或重建人员库。源码 ZIP 含完整运行代码、测试、说明及虚构预览；SHA256SUMS.txt 可校验 ZIP。
