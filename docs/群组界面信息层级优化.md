# 群组管理 UI 优化（版本保持 1.0.2）

本次改变的是**信息展示方式**，不改变 Teams 数据采集、身份审核、退群计数、历史保存与账号隔离。

## 默认显示
- 搜索群名、人员姓名或 ID；默认按群名排序。
- 60 天内变化的群：直接在群卡片中并列展示「新增人员」「减少人员」的姓名、最近几条发现日期和总人次。
- 单侧超过 3 条时，点击「查看全部」进入完整时间线；完整 ID 在时间线中保留。列表上的姓名悬停也可看到完整 ID。
- 60 天内没有保存变化的群：只显示一行简明的「近60天没有新增或减少记录」，不显示两块空卡片。
- 未保存到历史、但有带时间戳的待核查候选名单时：卡片直接显示这些人员，附「待核对」标记；已退群的历史候选不再当作最新变化。

## 按需展开
- 技术细节：群 ID、名单保存数量、缓存状态、最近读取时间等移到「更多信息与操作」。
- 群组详情里独立提供详细时间线、完整 ID、所有保存的记录；日期说明移入可展开区域。
- 批量操作保持默认折叠，可自行启用。

## 数据语义
UI 中的「新增」「减少」仅指 Teams 本地名单中相对于先前观察结果的变化，**不代表服务器正式确认加入、退出或准确发生时间**；日期为插件发现时间。不可凭人员相同姓名合并身份，不自动批准人员。
