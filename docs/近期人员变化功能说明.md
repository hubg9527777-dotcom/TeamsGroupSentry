# TeamsGroupSentry 1.0.2 — 按群名查看最近 60 天人员变化

打开 **安全中心 → 群组管理**：

1. 页面默认显示**全部群聊**，按群名排列，不再默认按风险或提醒级别排列。
2. 在顶部「查找哪个群？」输入群名，立即筛选。也支持使用成员姓名、完整人员 ID 或群组 ID 查找。
3. 点击群名称或右侧 **「查看60天记录」**，直接查看该群的人员变化记录。
4. 每条记录显示**插件发现变化的日期与时间、人员姓名、完整 ID**，并分别列出「新出现」和「名单少了」的人。默认最近 **60 天**，可临时切换 **7 / 30 / 60 / 90 天 / 全部已保存记录**；查看范围会在本次页面操作中沿用。
5. 群列表直接显示该群近 60 天观察到的变化次数及增减人数。即使近 60 天暂无已保存记录，也可以点击进入查看其他历史。

「近60天有变化」「需核对名单」「已标记退群」等仍在筛选菜单中，原先的全选、多选、批量确认名单、批量记录退出、监控级别设置保留在 **「批量处理群聊」** 下，需要时再打开。

## 数据说明

- **时间是插件首次发现 Teams 本地缓存名单差异的时间**，不是 Teams 服务器确认的真实进群、退群时间，也无法判断是谁邀请人员入群。
- 只显示本插件已存的事件。旧版未记录的变化无法倒推或补写；尚未读取到的姓名不会按群成员顺序猜测。
- 已退出群的历史记录仍保留；继续按原有的事件存储及清理规则维护（已处理历史事件约 180 天，且单群最多展示最近 300 条）。因此「60 天」是**查询时间窗口**，并非保证能取回所有历史操作。
- 本次仅修改页面浏览及查询方式，不改动账号绑定、身份信任、退群统计或 Chrome 权限。
