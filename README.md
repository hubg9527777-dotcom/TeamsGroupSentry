# TeamsGroupSentry

**基于本地成员基线的 Teams 群组智能巡检、成员变动监测与安全审计工具。**

适用于 Microsoft Teams 网页版（个人版）的 Chrome 扩展。通过观察浏览器中的 Teams 本地缓存、建立成员基线、识别值得关注的变化，并提供人工核查与本地备份管理。

**版本：** v1.0.0 · **兼容：** Chrome 120+ · **技术：** Manifest V3 · **运行方式：** 本地巡检

> **非官方项目。** TeamsGroupSentry 与 Microsoft 无隶属关系。所监测的是 Teams **本地缓存**，并非微软服务器确认的实时成员名单；异常提醒不等同于真实入群、退群或安全入侵。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 自动巡检 | 定期读取 Teams 本地群组及成员缓存。 |
| 成员变动监测 | 对照已保存的成员基线，识别新发现的人员 ID 与成员关系变化。 |
| 重点群组关注 | 分类管理重点群，提高待办事项的可见性。 |
| 人员与群组管理 | 查看群组及关联人员，支持备注、审核、同群成员切换。 |
| 名单异常核查 | 对疑似减少、替换或缓存质量异常保留原基线，等待人工核实。 |
| 自动故障恢复 | 缓存读取失败时重试，连续失败时重建内部读取器，不擅自刷新 Teams 页面。 |
| 状态同步提醒 | 工具栏图标、弹窗和 Teams 页面状态提示统一显示巡检情况。 |
| 加密备份与恢复 | 支持加密导出、历史比较及非破坏式缺失记录恢复。 |

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 🔴 红色 · 待处理 | 存在需要审核的新身份或重要未处理事件。 |
| 🟡 黄色 · 需关注 | 名单待核查、账号只读保护或巡检暂时失联。 |
| ⚪ 正常 / 最近已巡检 | 近期本地巡检未发现已知待办异常。 |

黄色不代表有人确实退群；正常状态也不等于微软服务器确认群组完全无异常。

## 安装

1. 获取源码 ZIP 并解压，找到包含 `manifest.json` 的目录。
2. 在 Chrome 打开 `chrome://extensions`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择该目录。
4. 登录并打开 [Teams 网页版](https://teams.live.com/v2/)，刷新页面一次。
5. 打开插件执行初次巡检；首次需要确认账号时，按照提示核对即可。

**从旧版升级：不要卸载原插件。** 先导出加密备份，再将新版文件覆盖至原扩展目录，重新加载扩展并刷新 Teams。这样可以尽量保留扩展 ID、已有群组记录、人员备注与审核历史。参见 [升级指南](UPGRADE_GUIDE.md)。

## 常用操作

- **查看人员：** 在群成员关系中进入人员详情，下拉切换同一个群中已记录的其他成员。
- **核查名单：** 在「群组中心 → 名单不确定 → 查看 / 命名」查看缓存差异；先在 Teams 原生成员列表核实，再决定是否更新基线。
- **比较备份：** 在「规则与备份」选择旧加密备份，执行历史比较，避免将“比较”误当成“恢复”。
- **巡检故障：** 插件会自动重试及重建内部读取器；长期无法恢复时仍会显示黄色提醒及失败原因。

## 隐私与安全

- 群组、人员、关联记录、审批与恢复点主要保存在当前浏览器的扩展数据区域。
- 插件不提供把成员数据上传至第三方服务器的遥测服务，也不负责收集或发送聊天消息。
- 手动导出的加密备份采用口令派生密钥与 AES-GCM 加密；请妥善保存密码。
- 浏览器配置文件中的本地记录和自动恢复点**没有额外应用层静态加密**，请保护电脑用户账号和浏览器配置文件。
- 不要向公开仓库提交真实成员名单、Teams ID、Token、密码、日志、浏览器配置文件或个人备份。

详情参见 [安全说明](SECURITY.md)。

## 使用限制

- 依赖 Teams 网页版的非公开缓存结构，Teams 更新后可能需要调整适配。
- 若服务器成员变化尚未写入浏览器缓存，插件无法即时发现。
- 缓存不完整时优先保护已保存名单，不能直接把缓存缺失认定为真实退群。
- 自动恢复不会强制刷新整个 Teams 页面，不能保证所有浏览器底层故障都能自动消失。
- 不自动移除群成员；不能替代 Microsoft 官方审计日志或权限管理功能。

## 开发与测试

基于原生 JavaScript、HTML、CSS 与 Chrome Manifest V3，正式运行不依赖第三方 npm 包。

```bash
npm test
```

自动化测试不等同于真实 Teams 登录环境的完整验证。

项目主要目录：`lib/`（缓存、备份与业务逻辑）、`popup/`（插件弹窗）、`ui/`（安全中心）、`overlay/`（网页状态提示）、`icons/`（图标）、`tests/`（测试）。
