# TeamsGroupSentry

**版本：1.0.2** · 适用于 `teams.live.com` 的 Chrome 扩展（Manifest V3）。

TeamsGroupSentry 帮助你在本地查看 Teams 群成员名单变化、核对陌生人员，并保留群组人员变化记录。它不会自动通过好友申请，也不会自动把陌生人设为可信。

## 主要功能

- **按群名查找**：搜索群组，直接查看近 **60 天**名单中新增、减少的人员及发现日期。
- **人员审核**：显示能可靠匹配的姓名、完整 Teams ID 和相关群聊；对陌生 ID 提醒核对。
- **批量处理**：多选群组，一次确认核对好的名单；保留相关历史记录。
- **退出群组**：记录已确认的本人退群，结束该群旧黄色提醒，历史群资料不删除。
- **聊天请求提醒**：以当前 Teams 页面可见证据为依据，避免把旧缓存误当作新请求。
- **本地数据保护**：按账号隔离记录，支持加密导出备份。

## 安装与更新

1. 在 [Releases](../../releases) 下载 `TeamsGroupSentry-1.0.2-install.zip` 并解压。
2. Chrome 打开 `chrome://extensions`，启用「开发者模式」，使用「加载已解压的扩展程序」，选择解压后的 `TeamsGroupSentry` 文件夹。
3. **更新旧插件前先导出加密备份**；将新版文件覆盖至原加载目录，并点击「重新加载」。不要直接卸载旧插件，以免丢失本地记录。
4. 刷新 Teams 页面和插件安全中心。

## 数据说明

插件记录的是**本地发现名单变化的时间**，不是微软服务器确认的实际进群或退群时间；不能仅凭缓存判断邀请者或保证实时在群总数。自动退群识别也取决于 Teams 网页实际界面。

项目使用原生 JavaScript，无第三方 npm 依赖；测试命令：`npm test`（Node.js 20+）。
